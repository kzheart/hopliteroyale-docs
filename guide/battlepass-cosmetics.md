# Battle Pass 与外观

Battle Pass 提供长期成长目标。玩家通过比赛行为获得经验，升级后领取免费或 Premium 奖励。

## 经验来源

| 来源 | BP 经验 |
| --- | --- |
| 击杀 | 50 |
| 助攻 | 20 |
| 胜利 | 200 |
| 参与 | 50 |
| 首次获得传奇武器 | 100 |
| 每日/每周任务 | 按任务配置 |

XP Boost 会影响最终获得经验。

## 赛季配置

每个赛季包含：

- 赛季 ID
- 赛季名称
- 开始日期
- 结束日期
- 每阶所需经验
- 每阶免费奖励
- 每阶 Premium 奖励

当前默认赛季：

| 赛季 | 时间 |
| --- | --- |
| 第一赛季：荣耀初现 | 2026-05-01 到 2026-07-31 |
| 第二赛季：边境回响 | 2026-08-01 到 2026-10-31 |

## 奖励类型

| 类型 | 说明 |
| --- | --- |
| COINS | 货币奖励 |
| COSMETIC | 外观奖励 |
| XP_BOOST | 经验倍率加成 |

## 外观类型

| 类型 | 外观 |
| --- | --- |
| 击杀特效 | 火焰终结、雷霆终结、彩纸终结 |
| 胜利舞蹈 | 机器人舞、月步庆祝、烟花谢幕 |
| 武器尾迹 | 火焰尾迹、附魔尾迹、灵魂尾迹 |

## 玩家命令

```text
/bp
/bp progress
/bp season
/bp quests
/bp claim all
/cosmetic
```

## 赛季切换

开启 `season.auto-switch` 后，插件会根据日期检测赛季状态。赛季结束后，进度会归档并重置，已获得的 Premium 外观保留。

建议赛季切换前：

1. 备份数据库。
2. 检查新赛季配置。
3. 在测试服模拟赛季日期。
4. 验证 `/bp season`、`/bp` 和奖励领取。
