# 职业图鉴

8 个职业的角色定位、各等级解锁内容、被动数值、起手打法、传奇配合建议。配置字段速查请看 [职业系统配置参考](./kits#完整配置参考)。

## 总览

| ID | 中文 | 图标 | 风格 | 主战场 |
| --- | --- | --- | --- | --- |
| `miner` | ⛏️ 矿工 | 铁镐 | 资源 / 工具 | 发育期挖矿，PvP 期破墙 |
| `archer` | 🏹 弓箭手 | 弓 | 远程输出 | 拉风筝压制 |
| `tank` | 🛡️ 坦克 | 皮革胸甲 | 前排扛伤 | 第一波交火占位 |
| `ninja` | 🥷 忍者 | 石剑 | 潜行刺客 | 抓单 / 绕后 |
| `alchemist` | 🧪 炼金师 | 酿造台 | 药水控制 | 反打与持续战 |
| `scout` | 🧭 侦察兵 | 指南针 | 信息探查 | 决定开战时机 |
| `lumberjack` | 🪵 伐木工 | 铁斧 | 木材囤积 | 速建 / 卡位 |
| `fisher` | 🎣 钓手 | 钓竿 | 水域经济 | 等待稀有收获 |

::: tip 通用规则
- 每个职业**独立等级**，从 Lv1 到 Lv5
- 升级需要的累计经验：Lv2 100 / Lv3 300 / Lv4 700 / Lv5 1500
- 经验来源：参与一局 +20 / 击杀一人 +10 / 获胜 +100
- 经验在比赛结算时落库，**下一局**自动应用当前等级
- 进入发育期后本局**禁止换职业**
- 选职业：`/class` GUI 或 `/class select <id>`
:::

## ⛏️ 矿工 `miner`

> *"快速开矿，稳住前期资源节奏。"*

### 各等级装备

| 等级 | 主装备 | 食物 |
| --- | --- | --- |
| Lv1 | 木镐 | 1 面包 |
| Lv2 | 木镐 | 2 面包（+1） |
| Lv3 | 石镐 | 2 面包 |
| Lv4 | 石镐 | 2 面包 |
| Lv5 | 铁镐 | 4 面包（+2） |

### 被动 / 属性

| 类型 | 内容 | 触发等级 |
| --- | --- | --- |
| 被动 | 挖矿（石头 / 矿石）20% 概率额外掉落 | Lv1 起 |
| 属性 | `block_break_speed` +20%（add_scalar） | **Lv4+** |

### 起手玩法

1. 丰饶角抢中心箱，**优先拿食物 + 武器**
2. 进入发育期立刻找石头 / 矿洞，2 分钟内堆出钻石装
3. 中后期合 ⛏️ 岩浆镐，PvP 阶段可以**直接挖墙**当突破口

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| ⛏️ 岩浆镐 | 完美契合，发育期挖矿 9 倍速度 |
| 🐉 龙之武士刀 | 后期补副武器 + 跑路 |

## 🏹 弓箭手 `archer`

> *"拉开距离，用箭雨压制战场。"*

### 各等级装备

| 等级 | 弓 | 箭 | 副武器 |
| --- | --- | --- | --- |
| Lv1 | 弓 | 8 支 | — |
| Lv2 | 弓 | 8 支 | — |
| Lv3 | 弓 | 16 支 | 木剑 |
| Lv4 | 弓 | 16 支 | 木剑 |
| Lv5 | 弓 | 32 支 | 石剑 |

### 被动 / 属性

| 类型 | 内容 | 触发等级 |
| --- | --- | --- |
| 被动 | 远程伤害倍率 ×1.10 | Lv1 起 |

### 起手玩法

1. 开局抢中心箱拿**任意护甲**——弓手没甲就是脆皮
2. 发育期到边缘地带，捡 / 合更多箭，找**高地**
3. PvP 期始终保持 10 格以上距离，配合队友踢皮球

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| 🪃 回旋环刃 | 远程被动 ×1.10 叠加，单发抵两发 |
| 🌊 守卫者炮 | 弩基底；蓄力时让队友挡前面 |
| 🐉 龙之武士刀 | 被贴脸瞬步拉开 |

## 🛡️ 坦克 `tank`

> *"顶住第一波交火，给队伍创造空间。"*

### 各等级装备

| 等级 | 防具 | 副武器 |
| --- | --- | --- |
| Lv1 | 皮靴 | — |
| Lv2 | 皮靴 | — |
| Lv3 | 皮靴 + 皮裤 | 木剑 |
| Lv4 | 皮靴 + 皮裤 | 木剑 |
| Lv5 | 全套皮甲（盔 + 衣 + 裤 + 靴） | 木剑 |

### 被动 / 属性

| 类型 | 内容 | 触发等级 |
| --- | --- | --- |
| 属性 | `max_health` +4.0（即多 2 颗心） | **Lv5** |

### 起手玩法

1. 开局**正面冲中心**，皮甲打底就敢挨第一波
2. 发育期有空就升级护甲到铁 / 钻
3. PvP 阶段当人形盾——你倒下了队伍才输

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| 💀 猎头者胸甲 | 多血量 + 多挨打 = Rage 涨满，反打机制契合 |
| 🌋 岩浆巨棒 | 站撸不怕反打，靠暴击磨损对方 |

## 🥷 忍者 `ninja`

> *"灵活切入，抓住落单目标。"*

### 各等级装备

| 等级 | 武器 | 蜘蛛眼 |
| --- | --- | --- |
| Lv1 | 木剑 | — |
| Lv2 | 木剑 | — |
| Lv3 | 木剑 | 2 |
| Lv4 | 木剑 | 2 |
| Lv5 | 石剑 | 4 |

### 被动 / 属性

| 类型 | 内容 | 触发等级 |
| --- | --- | --- |
| 被动 | 潜行时获得速度 I（`speed-amplifier: 0`） | Lv1 起 |
| 属性 | `sneaking_speed` +30%（add_scalar） | **Lv5** |

### 起手玩法

1. 不要冲中心——绕后捡漏
2. 发育期专门**抓单**：找单独挖矿 / 钓鱼的玩家
3. 蜘蛛眼是中毒材料，可以反手丢丢丢酿成毒药

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| 🐉 龙之武士刀 | 潜行 + 速度 + 瞬步，刺客成型 |
| 🌋 岩浆巨棒 | 暴击击退 + 潜行接近 = 偷一个甩一个 |

## 🧪 炼金师 `alchemist`

> *"用药水建立节奏和反打窗口。"*

### 各等级装备

| 等级 | 玻璃瓶 / 工具 | 备注 |
| --- | --- | --- |
| Lv1 | 3 玻璃瓶 | — |
| Lv2 | 3 玻璃瓶 | — |
| Lv3 | 酿造台 + 烈焰棒 + 3 药水 | — |
| Lv4 | 同 Lv3 | — |
| Lv5 | 同 Lv3 + 4 红石 | 红石用来延长药水持续 |

### 被动 / 属性

| 类型 | 内容 | 触发等级 |
| --- | --- | --- |
| 被动 | **自饮**药水持续时间 ×1.30 | Lv1 起 |

### 起手玩法

1. 开局抢箱子优先**烈焰棒 / 蜘蛛眼 / 苦力怕粉**等酿造材料
2. 发育期酿一组缓降 / 力量 / 抗性药
3. PvP 期"喝药 + 反打"循环 — 用持续 ×1.30 拖时间

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| 💀 猎头者胸甲 | 力量药水 + Rage 力量 III = 力量 IV 等效 |
| 🌊 守卫者炮 | 蓄力期吃缓降 / 抗性 |

| Lv1 | 指南针 + 木剑 |

| 类型 | 内容 | 触发等级 |

3. PvP 期决定开打时机：等敌人分散 / 给队友报方位

### 推荐传奇

| 传奇 | 为什么 |
| --- | --- |
| 🪃 回旋环刃 | 标记到的落单目标，远程一发双倍 |
| 🌊 守卫者炮 | 蓄力远程穿队伍 |

## 等级与经验

| 升到 | 累计经验 | 大概要打多少局 |
| --- | --- | --- |
| Lv2 | 100 | 5 局参与 |
| Lv3 | 300 | 15 局参与 / 3 把胜利 |
| Lv4 | 700 | 35 局参与 / 7 把胜利 |
| Lv5 | 1500 | 75 局参与 / 15 把胜利 |

::: tip 满级前怎么办
低等级也能打——**装备减少，被动 / 属性照常生效**。所以新手玩矿工 Lv1 就能享受 20% 额外掉落，弓手 Lv1 就有远程加成，不亏。
:::
