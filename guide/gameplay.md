# 玩法流程

## 比赛阶段

| 阶段 | 说明 |
| --- | --- |
| Waiting | 等待玩家达到开局人数 |
| Starting | 30 秒倒计时，人数不足会回到 Waiting |
| Cornucopia | 30 秒开局阶段，传送玩家、发放 Kit 起始物品、生成中心物资，PvP 禁用 |
| Grace | 12 分钟发育期，PvP 禁用，Kit 被动生效，参与经验结算 |
| PvP | 5 分钟 PvP 阶段，第一次缩圈开始 |
| Shrinking | 按 Arena 缩圈计划持续收缩边界，直到只剩最后一队 |
| Ending | 15 秒结算，宣布胜者、发放胜利经验、播放外观效果并卸载世界 |

## 胜负规则

Solo 模式下，最后一名存活玩家获胜。

Duo 和 Squad 模式下，以队伍为单位判定胜负。队伍所有成员都被淘汰后才算该队失败，最后存活的队伍获胜。

## 组队模式

| 模式 | 队伍人数上限 | 最低开局人数 |
| --- | --- | --- |
| Solo | 1 | 2 |
| Duo | 2 | 4 |
| Squad | 4 | 4 |

Duo 和 Squad 支持 Party 入场。玩家可以先在大厅组队，再使用 `/br quickplay duo` 或 `/br quickplay squad` 加入比赛。

## 保护与战斗

- Cornucopia 和 Grace 阶段禁用 PvP。
- 同队玩家无法互相伤害。
- 投射物伤害也会检查队友关系。
- 玩家死亡后会影响队伍存活判定。
- Duo/Squad 中存在队友复活机制，队员被击倒后可由队友救起。

## 成长结算

比赛会产生两类成长：

| 成长 | 来源 |
| --- | --- |
| Kit 经验 | 参与、击杀、胜利 |
| Battle Pass 经验 | 参与、击杀、助攻、胜利、首次获得传奇武器、赛季任务 |

玩家可以通过 `/kit info <id>` 和 `/bp progress` 查看进度。
