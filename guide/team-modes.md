# 组队模式(单/双/四排)

HopliteRoyale 支持三种组队规模。模式在**创建比赛**那一刻就决定,中途不能切换。

## 三种模式对比

| 模式 | 英文 | 队伍人数上限 | 最低开局人数 | 适合谁 |
| --- | --- | --- | --- | --- |
| 🧍 **单排** | Solo | 1 | 2 | 一个人一把,不依赖队友 |
| 👥 **双排** | Duo | 2 | 4 | 两个朋友互相罩,适合新人入门组队 |
| 👨‍👩‍👧‍👦 **四排** | Squad | 4 | 4 | 完整队伍,最考验配合,长局 |

## 怎么进对应模式

```text
/br quickplay              # 单排(默认)
/br quickplay solo
/br quickplay duo
/br quickplay squad
```

或者手动:

```text
/br create default duo     # 服主创建一局双排
/br join <id>              # 玩家加入指定比赛
```

## 队伍机制(双排 / 四排)

### 队伍颜色

每个队伍会被分配一种独立颜色,显示在:

- 玩家头顶名牌
- Tab 列表
- 侧边记分板上的存活队伍栏

颜色池由插件自动管理,**不会撞色**(直到颜色用完)。

### 友伤拦截

同队成员之间:

- 近战攻击 → ❌ 不掉血
- 弓箭 / 三叉戟 / 雪球 → ❌ 不掉血
- 火焰 / 持续伤害源 → ❌ 不掉血
- 喷溅药水(伤害类) → ❌ 不影响队友
- 喷溅药水(增益类) → ✅ 队友也能蹭到

### 队伍聊天

| 命令 | 说明 |
| --- | --- |
| `/tc <消息>` | 当前比赛的队伍频道(只有同队听得见) |
| `/t <消息>` | `/tc` 的快捷命令 |

队伍聊天**只在比赛中**生效。比赛外用 `/p`(Party 聊天)代替。

### 队友复活

四排 / 双排里,被击倒的队友**不会立即淘汰**:

1. 命中倒地后进入"被击倒"状态
2. 队友靠近持续 X 秒可以扶起
3. 没人扶 → 倒地超时 → 真正淘汰

::: tip 单排没有击倒
单排死了就是死了,没有救援机制。
:::

## Party(大厅组队)

Party 是**进入比赛之前**就存在的"长期队伍"——和朋友约好以后,在大厅里组好队,直接整队进同一场比赛。

### Party 命令

| 命令 | 说明 |
| --- | --- |
| `/party create` | 创建一个空 Party,你自动成为队长 |
| `/party invite <玩家>` | 邀请玩家(邀请 30 秒后过期) |
| `/party accept <队长>` | 接受指定队长的邀请 |
| `/party leave` | 离开当前 Party |
| `/party kick <玩家>` | 队长踢人 |
| `/party disband` | 队长解散 Party |
| `/party list` | 查看当前 Party 成员 |
| `/party chat <消息>` 或 `/p <消息>` | Party 聊天 |

### Party 进比赛流程

```
[大厅] /party create
       ↓
[大厅] /party invite Alice
       Alice 收到邀请 → /party accept <你>
       ↓
[大厅] /br quickplay duo
       → 整队一起进入同一场双排
```

::: warning Party 大小要匹配模式
3 人 Party 想进双排会失败(双排上限 2)。系统会提示你换模式或踢一个人。
:::

## 单/双/四排组队差异速记

| 项 | 单排 | 双排 | 四排 |
| --- | --- | --- | --- |
| 队友互伤拦截 | — | ✅ | ✅ |
| 队伍聊天 `/tc` | — | ✅ | ✅ |
| 队友复活 | — | ✅ | ✅ |
| 胜负判定单位 | 个人 | 队伍 | 队伍 |
| 胜利经验给谁 | 最后一人 | 整队 | 整队 |

---

## 服主小贴士

- 同时开多个模式的比赛实例没问题(`/br create default solo` + `/br create default squad`)
- 出生点数量请**至少匹配最大队伍数 × 期望队数**,避免大量复用
- 对线下网吧 / 公会赛,推荐固定开 4 排,减少匹配等待
