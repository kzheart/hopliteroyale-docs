# 项目概览

HopliteRoyale 是一个 Paper 1.21.11 服务端插件，目标是提供完整的 Hoplite 风格 Battle Royale 玩法。

## 核心特性

| 系统 | 说明 |
| --- | --- |
| 比赛循环 | 从等待玩家到最终结算的完整阶段机 |
| 队伍模式 | 支持 Solo、Duo、Squad，队友互伤拦截和队伍聊天 |
| 地图实例 | 基于 AdvancedSlimePaper 模板地图创建独立比赛世界 |
| Kit 职业 | 8 个基础职业，带起始装备、被动能力和等级成长 |
| 传奇武器 | 6 把传奇武器，支持合成、技能、冷却和图鉴 |
| Battle Pass | 赛季制等级、奖励领取、Premium 轨道和 XP 加成 |
| 外观 | 击杀特效、胜利舞蹈、武器粒子尾迹 |

## 技术要求

| 项 | 要求 |
| --- | --- |
| Java | 21 |
| 服务端 | Paper 1.21.11，正式地图功能需要 AdvancedSlimePaper 4.x |
| 数据库 | MySQL 8.x 优先，配置结构预留 PostgreSQL |
| 地图 | AdvancedSlimePaper 4.x MySQL loader |
| 插件版本 | 0.1.0 |

## 适合的服务器

HopliteRoyale 适合希望提供短局 PvP、赛季成长和可重复竞技体验的 Minecraft 服务器。它更接近独立小游戏服模式，而不是普通生存服附属玩法。

推荐从小规模测试开始，例如 4 到 8 人，确认数据库、地图模板和比赛阶段都稳定后再扩大容量。
