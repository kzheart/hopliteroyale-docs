# 项目简介

HopliteRoyale 是一个 **Paper 1.21.11** 服务端插件，目标是把"Hoplite 风格大逃杀"完整搬进 Minecraft——开局抢中心、发育、PvP、缩圈、最后一人(队)吃鸡。

## 一句话定位

> 玩家 30 秒进场，服主 5 分钟开服，外部插件 5 行代码接事件。

## 核心特性

| 系统 | 一句话说明 |
| --- | --- |
| ⚔️ 比赛循环 | 7 阶段自动推进：等待 → 准备 → 丰饶角 → 发育 → PvP → 缩圈 → 结算 |
| 👥 组队模式 | 单排 / 双排 / 四排，队友互伤拦截、队伍聊天、队友复活 |
| 🎯 职业系统 | 8 个职业（矿工/弓手/坦克/忍者/炼金/侦察/樵夫/渔夫），独立等级、被动 + 属性加成 |
| 🔥 传奇武器 | 6 把可合成传奇，主动技能 + 被动 + 冷却 + 图鉴 + 配方书 |
| 🩹 治疗规则 | 关闭原版自然回血，玩家头颅 / 金头按 `healing.yml` 注入即时治疗 + 持续效果 |
| 🧪 自定义合成 | `custom-crafts/` 下随便加配方，玩家头颅 / 金头 / 经验瓶等都是默认提供的示例 |
| 🪙 奖励钩子 | 不再内置战令/外观/钱包；通过 Bukkit 事件 + `config.yml` 命令模板对外开放 |
| 🌐 双语 i18n | en_US / zh_CN 内置，按客户端 locale 自动切换；玩家可见文案统一走 `Messages` 门面 |
| 🔌 公共 API | `:api` 子模块导出事件类型 + 契约接口，`dev-assets/sample-plugin` 提供独立外部插件示例 |
| 🗺️ 地图实例化 | 基于 AdvancedSlimePaper 4.x 模板，每局独立世界，结束自动卸载 |

## 适合谁开

- **独立小游戏服**：把它作为主玩法，搭配大厅插件直接跑
- **大型综合服**：作为 PvP / 活动子服，自己用奖励钩子接战令 / 商店 / 排行
- **公会 / 战队内部赛**：小规模训练场，4–8 人一晚十几局

不适合直接套到普通生存服上——它是"短局竞技"的设计，不是常驻挂机玩法。

## 技术清单

| 项 | 要求 |
| --- | --- |
| Java | 21 |
| 服务端 | **AdvancedSlimePaper 4.x**（基于 Paper 1.21.11） |
| 数据库 | MySQL 8.x（优先） / PostgreSQL 15+（规划中） |
| 地图后端 | ASP MySQL loader |
| 构建 | Gradle Kotlin DSL + paperweight-userdev + Shadow（Mojang mappings） |

::: tip 普通 Paper 能跑吗？
非地图功能可以在普通 Paper 1.21.11 测试。但**正式开服请用 AdvancedSlimePaper 4.x**——地图模板的加载/卸载依赖 ASP 4.x 的 API。
:::
