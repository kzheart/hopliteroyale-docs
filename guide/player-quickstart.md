# 玩家 · 3 分钟上手

> 第一次进 HopliteRoyale 服？照着这页打一遍，基本就懂了。

## ① 进场：一条命令搞定

| 想干什么 | 输入这个 |
| --- | --- |
| 单排，自己打 | `/br quickplay` 或 `/br quickplay solo` |
| 双排（2 人队） | `/br quickplay duo` |
| 四排（4 人队） | `/br quickplay squad` |
| 离开当前比赛 | `/br leave` |

::: tip 想和朋友一起？
先在大厅 `/party create`，然后 `/party invite <好友 ID>`。组好队再 `/br quickplay duo` 或 `squad`，系统会**整队一起进场**。
:::

## ② 选职业：决定你这局的开局装备

进场后（等待 / 准备 / 丰饶角阶段），输入 `/class` 打开职业选择 GUI，或者直接：

```text
/class select archer       # 选弓手
/class info archer         # 看自己弓手等级
```

8 个职业怎么选？简化版推荐：

| 你想 | 推荐职业 |
| --- | --- |
| 苟发育、最稳 | 🛡️ 坦克 / ⛏️ 矿工 |
| 远程秀 | 🏹 弓手 |
| 贴脸切人 | 🥷 忍者 |
| 喝药打架 | 🧪 炼金 |
| 找人 | 🧭 侦察 |
| 砍木头堆塔 | 🪵 樵夫 |
| 钓鱼出货 | 🎣 渔夫 |

详见[职业图鉴](./class-list)。

::: warning 发育期之后不能换职业
进入"发育期"那一刻起，本局职业**锁定**。换职业要等下一局。
:::

## ③ 看懂 7 个阶段

| 阶段 | 你该做什么 |
| --- | --- |
| 🕒 **等待中** | 凑人数。可以选职业、组队、聊天 |
| ⏳ **准备开始** | 30 秒倒计时。这时候人不够会回到等待 |
| 📦 **丰饶角** | 30 秒。**冲中心抢箱子**！但这阶段还**禁止 PvP** |
| 🌱 **发育期** | 12 分钟。**PvP 仍禁用**，赶紧打怪、挖矿、合传奇 |
| ⚔️ **PvP** | 5 分钟。开战！第一次缩圈也从这里开始 |
| 🌀 **缩圈** | 圈持续收紧，直到决出最后一人/队 |
| 🏁 **结算** | 15 秒。结算名次、卸载地图 |

详见[比赛七阶段](./phases)。

## ④ 战斗中常用命令

| 命令 | 用途 |
| --- | --- |
| `/t <消息>` 或 `/tc <消息>` | 给队友发消息（只有队友看见） |

## ⑤ 越打越强：职业成长

打一局会累计**职业经验**：

```
打比赛 → 拿击杀 → 吃鸡
   ↓        ↓       ↓
   都给当前职业累加经验
```

| 行为 | 职业经验 |
| --- | --- |
| 参与一局 | +20 |
| 击杀一人 | +10 |
| 获胜 | +100 |

升级所需累计经验：Lv2 100 / Lv3 300 / Lv4 700 / Lv5 1500。

随时查：`/class info <id>`

## ⑥ 治疗：玩家头颅 / 金头

PvP 与缩圈阶段下，**原版自然回血是关闭的**，主要的"补血"手段是：

- **玩家头颅**：击杀对手会掉落，右键吃下立即恢复 4 颗心 + 短暂回血
- **金头**：金锭包裹玩家头颅合成，恢复量更多 + 附加 1 分钟伤害吸收
- 普通食物 / 治疗药水仍可用，按 `healing.yml` 服主可调

::: tip 倒地状态
被打倒（队友模式下）时**不能**吃头颅或喝药，必须等队友把你扶起来。
:::

## ⑦ 最常见的新手疑问

**Q1. 我和队友互砍没伤害？**
对，这是友伤拦截。和你在同一队伍/Party 里的人**永远不会**互伤，弓箭也不会。

**Q2. 我刚开局就被打了怎么没掉血？**
丰饶角 + 发育期一共有 12 分多钟**完全禁 PvP**，这段时间任何攻击都不会生效。

**Q3. 我下线再上能继续这局吗？**
不能。一旦你离场，这一局就结束了——本质上是被淘汰。下次重新匹配。

**Q4. 我的职业等级会丢吗？**
不会，职业经验存数据库，跨局保留。

**Q5. 选错职业了能改吗？**
能，但只能在丰饶角之前。之后就锁死了。
