::: tip 通用规则
- 所有武器都是 `custom-model-data: 1001`，配资源包才有外观差异，**不上资源包不影响功能**
- 主动技能冷却显示在物品栏的 cooldown 上；冷却**绑在玩家身上**，换手 / 丢出去捡回来不会重置
- 物品身份用 PDC 持久化，**不**靠 displayName / lore 识别——附魔、命名、损耗都不会让它失效
- 想看官方蓝图：进游戏 `/legendary atlas`
:::

## 🐉 龙之武士刀 `dragon_katana`

> *"持有时获得永久速度 II。潜行 + 右键，向前瞬步 8 格。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:netherite_sword` |
| 配方类型 | **铁砧** |
| 配方 | 钻石剑（左） + 龙首（右） |
| 经验消耗 | **8 等级** |

### 技能

| 技能 | 类型 | 行为 | 数值 |
| --- | --- | --- | --- |
| Dragon Speed | 被动 / Tick | 持有时持续叠加速度药水（25 ticks 刷新） | `speed-amplifier: 1`（速度 II） |
| Dragon Blink | 主动（潜行 + 右键） | 沿视线方向瞬步 8 格；若视线方向有方块则站到方块顶上；附末影传送音效 + 紫色门户粒子 | `blink-range: 8`，冷却 `5000 ms` |

### 玩法

- **拉距离 / 进场**两用：被弓手拉风筝时瞬步绕背，被贴脸时瞬步拉开
- 速度 II 是**永久叠加**的，进背包不消失（只要主手 / 副手 / 物品栏里有这把）
- 不要瞬步进岩浆 / 虚空——传送目标点是几何点位，不会做安全检查

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| 🥷 忍者 | 潜行被动 + 速度叠加，绕背刺客成型 |
| 💀 猎头者胸甲 | 进场后直接挨打攒 Rage，速度 + 力量爆发 |
| 🌋 岩浆巨棒 | 瞬步进场后切棒 Crit 击退，二段连招 |

## 🌋 岩浆巨棒 `magma_club`

> *"暴击时有 30% 概率震退目标，并撕裂一件护甲耐久。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:golden_axe` |
| 配方类型 | **工作台 3×3** |

```
D G D
D S D
. S .

D = 钻石     G = 金块
S = 烈焰棒   . = 空
```

### 技能

| 技能 | 类型 | 行为 | 数值 |
| --- | --- | --- | --- |
| Magma Crit | 被动（玩家暴击命中时） | 30% 几率把目标向背后击飞（速度向量 ×1.5，Y +0.4），并随机给目标的一件护甲扣耐久 | `knockback-chance: 0.30`，`armor-damage: 50` |

### 玩法

- 想触发就**起跳下劈**——必须是原版「暴击」（空中下落攻击）才会触发
- 撞墙击退是关键：在边境 / 缩圈线附近打能直接把人推出血圈
- 50 耐久护甲损耗对皮 / 链 / 铁甲都是可观伤害，对穿钻 / 下界合金的不那么疼

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| 🛡️ 坦克 | 站撸不怕反打，靠暴击磨损对方 |
| 🪵 樵夫 | 同样是斧基底，等级高了过渡顺滑 |
| 缩圈期单杀 | 把人推出去，让边境爆头 |

## 💀 猎头者胸甲 `headhunter_chestplate`

> *"穿戴后获得力量 I。造成或承受伤害积攒 Rage。Rage 满值时爆发力量 III + 速度 II，持续 15 秒。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:netherite_chestplate` |
| 配方类型 | **工作台 3×3** |

```
. N .
N C N
. N .

N = 下界之星     C = 钻石胸甲
```

### 技能

| 技能 | 类型 | 行为 | 数值 |
| --- | --- | --- | --- |
| Rage（被动 / Tick） | 装备时持续力量 I | 始终给玩家力量 I，每 25 ticks 刷新 | — |
| Rage 积攒 | 被动（伤害事件） | 造成伤害 +5 Rage，受到伤害 +10 Rage，上限 100 | `damage-dealt-rage: 5`，`damage-taken-rage: 10`，`rage-max: 100` |
| Enrage 暴怒 | 自动触发 | Rage 满 → 重置为 0，进入 15 秒暴怒：力量 III + 速度 II | `enrage-seconds: 15` |

### UI

暴怒条以 BossBar 显示在玩家屏幕顶部，红色，文案 `Rage 当前/100`。

### 玩法

- **挨打也涨 Rage**，且涨得比打人更多——新手装这件穿插在前线就能一路涨条
- 进入暴怒前 5 秒最关键：找视野好的位置，触发时直接接战
- 单论"贴脸 15 秒爆发"，本游戏没有更猛的

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| 🛡️ 坦克 | 多血量 + 多挨打 = 多 Rage |
| 🐉 龙之武士刀 | 速度叠加，Rage 期间速度叠到上限 |
| 🧪 炼金师 | 自饮力量药水持续延长，叠到力量 IV 级伤害 |

## ⛏️ 岩浆镐 `magma_pickaxe`

> *"挖掘石头或矿石时，引爆 3x3x3 熔岩矿脉。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:iron_pickaxe` |
| 配方类型 | **工作台 3×3** |

```
O G O
G P G
O G O

O = 黑曜石     G = 火药
P = 钻石镐
```

### 技能

| 技能 | 类型 | 行为 | 数值 |
| --- | --- | --- | --- |
| Magma Blast Mine | 被动（BlockBreak 事件） | 挖石头 / 矿石时，连带破坏中心方块周围 3×3×3 区域，所有掉落物自动进背包，背包满了才掉地上 | `radius: 1`（即 3×3×3） |

### 限制

- **出生点 15 格半径内不触发**——防止开局直接把补给箱挖飞
- 只对石头家族 / 矿石生效，木头、泥土、玻璃这些不会触发
- 不属于"破坏方块"事件链的方块（如村民交易刷的、机器生成的）也不触发

### 玩法

- 矿工的核心装备，发育期挖矿堆资源 = 别人 9 倍速度
- PvP 阶段也能用来**破墙**：直接挖一面石头墙，背包瞬间塞满
- 缩圈期可以挖掉对方的速建塔，把高位敌人摔下来

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| ⛏️ 矿工 | Lv4+ 挖掘速度 +20%，叠加岩浆镐效率爆炸 |
| 🪵 樵夫 | 互补——一个砍木一个挖矿，发育期物资双丰收 |

## 🌊 守卫者炮 `guardian_cannon`

> *"右键蓄力 2 秒，释放持续灼烧的守卫光束。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:crossbow` |
| 配方类型 | **工作台 3×3** |

```
S S S
S C S
S H S

S = 海晶碎片   C = 弩
H = 海洋之心
```

### 技能

| 技能 | 类型 | 行为 | 数值 |
| --- | --- | --- | --- |
| Guardian Cannon | 主动（右键） | 蓄力 40 ticks（2 秒），蓄力期间被打 → 中断并收到红色提示。蓄力满后释放 100 ticks（5 秒）持续光束，每 tick 通过 raytrace 检测命中目标，每次命中扣血 | 蓄力 `charge-ticks: 40`，光束 `beam-ticks: 100`，每命中 `damage: 4.0`，冷却 `cooldown-ms: 30000` |

### 玩法

- **不是即时伤害**——是 5 秒持续光束。扫一队人比单点更划算
- 蓄力期间动作要少，受任何 EntityDamage 都会打断
- 30 秒冷却很长，每场最多用 4–6 次。要打就打关键波

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| 🛡️ 坦克 | 蓄力时让坦克挡前面 |
| 🧪 炼金师 | 蓄力期吃缓降 / 抗性药 |
| 🎣 钓手 | 海洋之心可以钓出来，前期凑配方更稳 |

## 🪃 回旋环刃 `ricochet_chakrams`

> *"投掷后在敌人间弹射，回旋归来时自动收回。"*

| 字段 | 值 |
| --- | --- |
| 基础物品 | `minecraft:snowball` |
| 配方类型 | **工作台 3×3** |

```
S S S
. B .
S S S

S = 石头     B = 烈焰棒
```

### 技能

| 阶段 | 行为 | 数值 |
| --- | --- | --- |
| 第一次命中 | 6.0 伤害，向投掷者方向反弹（速度向量 1.4） | `first-hit-damage: 6.0` |
| 第二次命中（反弹途中） | 4.0 伤害，**自动放回投掷者背包**（背包满则掉地上） | `return-hit-damage: 4.0` |

PDC 标记 `CHAKRAM_PROJECTILE` / `CHAKRAM_BOUNCED` 跟踪状态，第三次不会再弹。

### 玩法

- 单发等价于普通投掷的双倍输出，**前提是反弹路径上还有人**
- 多人混战时一发能贯两队
- 反弹方向是「回投掷者」，不是几何反弹——所以投掷者要原地接

### 推荐组合

| 搭档 | 为什么 |
| --- | --- |
| 🏹 弓手 | 远程被动 ×1.10，远程多手段叠输出 |
| 🧭 侦察兵 | 50 格标记发现落单目标后远程秒杀 |
