# Kit 职业

Kit 会影响玩家开局装备和部分被动能力。玩家通过参与、击杀和胜利获得 Kit 经验。

## 通用等级

| 等级 | 说明 |
| --- | --- |
| Lv1 | 基础装备 |
| Lv2 | 小幅补给提升 |
| Lv3 | 主装备升级 |
| Lv4 | 开始获得关键被动 |
| Lv5 | 满级能力 |

默认升级经验：

| 目标等级 | 所需经验 |
| --- | --- |
| Lv2 | 100 |
| Lv3 | 200 |
| Lv4 | 300 |
| Lv5 | 400 |

## 职业列表

| Kit | 定位 | 关键内容 |
| --- | --- | --- |
| Miner | 挖矿发育 | 镐、面包、急迫、挖矿额外掉落 |
| Archer | 远程输出 | 弓箭、近战备武器、远程伤害加成 |
| Tank | 生存前排 | 皮甲、木剑、满级生命值提升 |
| Ninja | 机动近战 | 木剑或石剑、蜘蛛眼、潜行速度 |
| Alchemist | 药水收益 | 玻璃瓶、酿造台、烈焰棒、药水持续时间提升 |
| Scout | 侦查 | 指南针、木剑、附近敌人粒子标记 |
| Lumberjack | 木材发育 | 斧头、额外木材、连锁砍树 |
| Fisher | 钓鱼收益 | 钓竿、水桶、钓鱼效率和稀有收益 |

## 选择方式

玩家可以使用：

```text
/kit
/kit select miner
/kit info miner
```

在 Waiting、Starting 和 Cornucopia 阶段可以选择或更换 Kit。Grace 之后禁止更换，避免中途切换能力。

## 经验来源

| 来源 | Kit 经验 |
| --- | --- |
| 参与比赛 | 20 |
| 击杀 | 10 |
| 获胜 | 100 |

经验写入数据库，下一局会读取并应用玩家当前 Kit 等级。
